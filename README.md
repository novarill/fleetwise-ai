# HINO FleetWise AI

本專案為 **2026 和泰 AI 黑客松**提案，主要用於整理 HINO FleetWise AI 的產品需求、系統架構、介面設計與開發規劃。

HINO FleetWise AI 以商用車隊管理為核心，聚焦於 **行車安全預防** 與 **車隊節能省油** 兩大方向，透過 AI 技術輔助駕駛員、調度人員、車隊管理者及維修人員進行車隊營運與管理決策。

## 文件說明

### 1. 介面預覽

存放專案的使用者介面設計與畫面預覽，涵蓋駕駛員、調度人員、車隊管理者及維修人員四種使用角色，供團隊參考系統的視覺呈現、功能配置及操作方式。

| 檔案名稱 | 說明 |
| :--- | :--- |
| `1-driver-app.png` | **駕駛員介面**：呈現駕駛員行車過程中的功能操作與資訊顯示。 |
| `2-dispatcher-dashboard.png` | **調度人員儀表板**：呈現車隊調度、路線規劃及營運資訊管理介面。 |
| `3-manager-app.png` | **車隊管理者介面**：呈現車隊整體營運狀態、安全管理及節能分析資訊。 |
| `4-maintenance-dashboard.png` | **維修管理儀表板**：呈現車輛維護、保養管理及異常狀態追蹤介面。 |

### 2. 架構圖
